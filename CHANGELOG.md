## [Unreleased] - ReleaseDate

## [1.0.2] - 2026-02-01

### Added

- New command-line option `--no-footer` to disable footer display in output
- New command-line option `--max-speed` to set the maximum speed used in bytes usage graph
- Automatic retry functionality for SSH connections to handle connection failures gracefully

## [1.0.1] - 2026-01-30

### Fixed

- Fix npm package binary

## [1.0.0] - 2026-01-30

### Added

- Initial release of ssh-chain, an HTTP proxy server that tunnels traffic through SSH SOCKS5 tunnels
